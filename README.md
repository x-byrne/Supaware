# SuperVis

Australian Superannuation Performance Visualisation Framework

A vanilla-JS, Chart.js-based visualisation tool for exploring and comparing Australian superannuation fund options and asset class returns.

## Features

- Select multiple superannuation fund types and asset classes
- Compare performance over custom time periods
- View indexed values, growth rates, or raw returns
- Interactive range slider for period selection
- Responsive design with DM Sans typography

## Data

Daily superannuation performance data sourced from Australian super fund performance reporting.

## Development

```bash
npm start
```

Serves the site locally via `npx serve`.

## Deploy to GitHub Pages

```bash
npm run deploy
```

Copies web assets into `docs/` and commits for GitHub Pages deployment.
